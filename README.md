# Drift

An ambient mixer for deep focus - rain, thunder, wind, fire and waves, blended with sliders.
Every sound is synthesized live in the browser with the Web Audio API: no audio files, no loops, no backend.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/drift/

Features: five synthesized channels with live modulation (thunder swells, wind gusts, fire crackle,
wave swells), a real-time frequency visualizer, and a sleep timer with a slow fade-out.

Idea #2 from the iLanis App Factory - one new app, every hour.
